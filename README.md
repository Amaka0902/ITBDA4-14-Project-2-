This project applies big data analytics techniques to text data across four tasks. First, a MapReduce keyword search was implemented in R using Hadoop Streaming, with a mapper emitting key-value pairs for each keyword occurrence and a reducer aggregating the counts across a document collection. Second, Latent Dirichlet Allocation (LDA) topic modelling with Gibbs sampling was applied to a corpus of news articles to identify the main themes, which were interpreted through the top terms of each topic and visualised as bar charts and word clouds. Third, a proof-of-concept web text API was built by scraping public web pages with rvest, preprocessing the text with regular expressions, and producing extractive summaries with two methods, TextRank and frequency-based sentence scoring, which were compared by sentence length and content. Fourth, an Extract, Transform and Load (ETL) workflow collected 76 unique records from eight Our World in Data pages, cleaned a 25-record sample (denoising, median imputation of missing values, and a before/after quality audit), loaded it into PostgreSQL, and analysed it with SQL window functions and aggregate queries. The work, with its notebooks, datasets and SQL script, is published in a GitHub repository to support reproducibility. Together, the tasks show how distributed processing, statistical text mining, web data acquisition and database-backed ETL can turn unstructured text into structured, analysable information, while the limitations noted (such as simulated view counts in Question 4 and the need to re-run Question 3 with the corrected cleaning function) show where further validation is needed.
